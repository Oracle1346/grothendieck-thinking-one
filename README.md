# grothendieck-thinking

将亚历山大·格罗滕迪克的数学研究方式蒸馏为一份中文 AI 技能：从具体问题出发，寻找足以改变解题能力的结构，再返回具体结果。

核心要求：每一次抽象都要说明保留了什么信息、解决了什么困难，并完成至少一个实际推导或验证。

## 文件

```text
grothendieck-thinking/
├── SKILL.md
├── README.md
└── references/
    ├── examples.md
    └── sources.md
```

`SKILL.md` 包含触发条件、执行流程、八项按需选用的操作、停止规则和输出约定。它可以独立阅读。参考文件提供教学示例与来源说明。

## 使用

在支持 `SKILL.md` 目录式技能的工具中，将整个文件夹放入该工具的技能目录，并按该工具的方式加载。各工具的技能目录与调用方式不同；请按所用工具的说明安装和加载。

也可以让 AI 读取 `SKILL.md`，把它作为当前任务的方法说明，再提供实际问题。例如：

> 使用 grothendieck-thinking 分析下面的问题。先给一个具体例子，再选择最有用的一至两项结构操作。请给出实际推导，说明抽象带来的收益，并区分已证明、依赖假设和类比。问题：……

数学任务示例：

> 我只看一个概形的普通点，能恢复它吗？请用最小反例解释缺失的信息，再说明什么样的观察能够恢复对象。

> 我有一族对象，每个纤维都同构，能否断言整个族平凡？请先说明缺少哪些条件，再给反例或适用定理。

> 一个问题每处都有局部解，为什么仍可能没有全局解？请把局部存在、兼容性和粘合定理分开。

迁移任务示例：

> 多个数据源都返回金额，但接入后总出现币种与精度错误。请用结构重构改进接口，交付最小模型与验收条件，并明确哪些地方只是数学方法的类比。

## 八项操作

1. 从直觉与例子提炼定义。
2. 相对化：研究背景、参数与族。
3. 函子化：观察全部相容的关系。
4. 用泛性质刻画目标，分开处理存在性。
5. 从局部解走向兼容数据与有效下降。
6. 为明确的构造需要扩大框架。
7. 将失败定位为可检验的障碍。
8. 从共同结构提出统一研究主题。

它们不是必须依次完成的八个阶段。简单问题优先直接解决；跨领域使用要明确标注现代类比。
